## 1. 리서치 발표 (UX 리서처)
- 토스의 One-thing-per-page, 카카오 선물하기의 상황 우선 탐색, 29CM의 2열 에디토리얼 그리드, 2026 Wizard + Sticky CTA 패턴을 공유했다.
- 현황 감사 결과 P1~P8을 보고했다. 생성 페이지는 약 15화면 높이에 결정 지점 11개 이상이 있다.
- 특히 **P4(수령인 화면의 Admin 링크 노출)**는 UX 문제를 넘어 보안·신뢰 이슈라고 강조했다.

## 2. 주요 토의

### 논쟁 1. "4단계는 너무 많은가? 3단계로 줄일 수 없나?"
- **프로덕트 디자이너**: 상황·예산 / 선물 / 카드 / 확인 4단계를 제안한다. 단계마다 결정은 1~2개다.
- **인터랙션 디자이너**: 카드 꾸미기와 확인을 합쳐 3단계로 가면 더 빠르지 않을까?
- **PM**: 에스크로 가승인(최대 예산 결제)은 금액이 크게 걸리는 행위라 **결제 전 요약 확인 단계가 반드시 필요**하다. 환불 정책 고지 공간도 필요하다.
- **결정**: **4단계를 유지**한다. 대신 1단계에서 상황을 고르면 예산과 추천 선물, 카드 문구까지 자동으로 채워 사실상 '다음'만 눌러도 진행되게 한다(토스의 Easy to answer 원칙).

### 논쟁 2. "카드 꾸미기 옵션 5종(테마, 폰트, 포장, 씰, PIN)을 어디까지 노출할까?"
- **비주얼 디자이너**: 테마는 미리보기 효과가 가장 커서 기본 노출해야 한다.
- **UX 리서처**: 폰트·포장·씰은 사용률이 낮을 것으로 예상한다. 첫 화면에 다 보이면 다시 인지 과부하가 생긴다.
- **결정**: 기본 노출은 **보내는 사람 이름, 메시지(AI 추천 포함), 테마**다. **'더 꾸미기' 아코디언**에 폰트·포장·씰을 담고, **'받는 분 옵션' 아코디언**에 직접 입력 허용과 PIN을 담는다. 미리보기 카드는 단계 최상단에 고정한다.

### 논쟁 3. "MD Pick 섹션은 어디로?"
- **프로덕트 디자이너**: 현재는 첫 화면에 크게 있어 생성 플로우를 방해한다.
- **비주얼 디자이너**: 에디토리얼 감성의 핵심 자산이라 없애면 안 된다.
- **결정**: 2단계(선물 고르기)로 옮기고 **'에디터 추천' 접이식 섹션**으로 둔다. 기본값은 접힘이다.

### 논쟁 4. "내비게이션: 상단 메뉴 vs 하단 탭바"
- **접근성 담당**: 상단 메뉴 4개가 모바일에서 줄바꿈되고 터치 타깃이 작다(약 28px).
- **디자인 리드**: 모바일 웹뷰(카톡 인앱 브라우저)가 주 사용 환경이니 하단 탭바가 표준이다.
- **PM**: Admin은 일반 사용자 메뉴에서 빼야 한다.
- **결정**: 하단 탭바 3개(만들기 / 선물함 / 고객센터), 헤더에는 로고와 언어 토글만 둔다. Admin은 푸터 링크로 옮긴다. **수령인(/gift/*) 화면은 로고만 있는 미니멀 헤더를 쓰고 탭바를 두지 않는다.**

### 논쟁 5. "생성 단계의 상품 카드에 가격을 노출해도 되나?"
- **PM**: 보내는 사람 화면에서는 가격 노출이 허용된다(예산 판단에 필요). **수령인 화면만 100% 비노출**이다.
- **결정**: 2열 CompactProductCard는 보내는 사람 전용이므로 가격을 표시한다. 수령인은 기존 `ProductCard hidePrice`를 유지하고, **비노출을 자동 테스트로 보장**한다.

### 논쟁 6. "브라우저 confirm()은 어떻게?"
- **인터랙션 디자이너**: 바텀시트 확인창(ConfirmSheet)으로 바꾼다. ESC와 배경 탭으로 닫히고 포커스는 확인 버튼으로 간다.
- **결정**: 공용 `ConfirmSheet` 컴포넌트를 만들어 대시보드 선물 취소에 적용한다.

## 3. 디자인 토큰 합의 (비주얼 디자이너)
- 컬러는 유지한다: Primary `#3b483a`, Accent `#a38974`, Canvas `#faf9f6`, Line `#eae6df`.
- 시맨틱 CSS 변수(`--sp-*`)를 추가하고 신규 컴포넌트부터 토큰을 사용한다.
- 신규 컴포넌트 본문은 최소 12px로 하고, 9~10px은 라벨·캡션에만 제한적으로 쓴다. 신규 화면에서는 이모지를 자제한다.
- 모션: `cubic-bezier(.16,1,.3,1)`, 단계 전환 0.35s, `prefers-reduced-motion`을 존중한다.
